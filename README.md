# Go Final Project: Task Scheduler with SQLite

    Дипломный проект на языке Go. Веб-сервер с REST API для управления задачами, планировщиком повторений и базой данных SQLite.

# Выполненные задания со звёздочкой

    Все пункты технического задания, включая аутентификацию и Docker.

## Инструкция по запуску (Локально)

1.  Запустите сервер (с паролем для включения авторизации):
    ```bash
    TODO_PASSWORD=12345 go run main.go
    ```
    *(Если хотите запустить без пароля, оставьте переменную пустой или не указывайте её).*
    
2.  Откройте в браузере: `http://localhost:7540`
3.  Страница входа: `http://localhost:7540/login.html`

## Сборка и запуск через Docker
1.  Соберите образ:
    ```bash
    docker build -t todo-planner .
    ```
2.  Запустите контейнер:
    docker run -d --name todo-planner \
      -p 7540:7540 \
      -v my-scheduler-data:/data \
      -e TODO_PASSWORD=12345 \
      todo-planner
3.  Откройте `http://localhost:7540`.

### Инструкция по тестированию

1.  Убедитесь, что переменная `Token` в файле `tests/settings.go` содержит актуальный JWT-токен (если включена аутентификация).
    *   Чтобы получить токен: отправьте POST запрос к `/api/signin` с правильным паролем.
    *   Вставьте полученный токен в `var Token = "..."` в `tests/settings.go`.
2.  Запуск всех тестов:
    ```bash
    go test ./tests
    ```
3.  Запуск конкретных тестов (например, проверка редактирования):
    ```bash
    go test -run ^TestEditTask$ ./tests
    ```
