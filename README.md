# todo-scheduler

Планировщик задач на Go с REST API, SQLite, аутентификацией и правилами повторения.

## Функционал

- Добавление, получение, обновление, удаление задач.
- Правила повторения: `d N`, `y`, `w D1,D2,...`, `m D1,D2,...[, M1,M2,...]`.
- При выполнении задачи — либо удаление, либо перенос на следующую дату по правилу.
- Поиск по тексту и дате.
- Аутентификация через `/api/signin` и проверку куки `token`.
- Docker-образ и compose для запуска.

## Запуск локально

```bash
export TODO_PORT=7540
export TODO_DBFILE=scheduler.db
export TODO_PASSWORD=12345
go run cmd/server/main.go
